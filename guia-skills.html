Banco de Custos CWICR — Busca e Precificação

55.719 itens de custo de construção em 30 regiões do mundo

O que é o banco CWICR?

O CWICR (Construction Work Items Cost Reference) é uma base de dados com 55.719 itens de custo de construção, com preços de mão de obra, material e equipamento por região. As skills CWICR permitem usar esse banco para orçar, comparar e validar preços de serviços de obra. Importante: os preços são americanos — use como referência estrutural e adapte para preços regionais brasileiros.

Busca Semântica no Banco CWICR
/ddc-obra:ddc-semantic-search-cwicr
Busca no banco de dados CWICR usando busca semântica por vetores. Encontra itens de serviço similares e recursos para composição de custo.
Use quando: Quiser encontrar a composição de custo de qualquer serviço de obra — ex: "revestimento cerâmico 60x60" ou "impermeabilização de laje". A busca entende o que você quer mesmo sem o termo exato.
Orçamento Banco de dados
Calculadora de Custos CWICR
/ddc-obra:ddc-cwicr-cost-calculator
Calcula custos usando metodologia de composição do CWICR. Decompõe em mão de obra, materiais e equipamentos com preços transparentes.
Use quando: Precisar montar uma composição de custo unitário para um serviço específico, decompondo em insumos — similar ao que faz o SINAPI, mas com estrutura mais detalhada.
Orçamento Composição
Combinador de Quantidades com CWICR
/ddc-obra:ddc-cwicr-quantity-matcher
Combina quantitativos do projeto com itens do banco CWICR. Mapeia categorias de elementos a códigos de custo e gera orçamento vinculado a quantidades.
Use quando: Tiver o levantamento de quantitativos (m², m³, un.) e quiser gerar automaticamente o orçamento vinculando cada serviço ao seu custo unitário.
Orçamento Quantitativo
BIM + Orçamento Automático (CWICR)
/ddc-obra:ddc-bim-cost-estimation-cwicr
Orçamento automatizado a partir de modelos BIM usando o banco CWICR com 55.719 itens. Classificação por IA + busca vetorial para precificação precisa.
Use quando: Tiver um modelo BIM (Revit/IFC) e quiser gerar orçamento automaticamente, sem precisar lançar item por item manualmente.
BIM Orçamento Avançado
